


# 🍇 Click Açaí

Site de pedidos online para a **Click Açaí**, açaiteria local na Zona Sul de Natal/RN. Interface para montagem de produtos, carrinho de compras e finalização de pedido via WhatsApp.

🔗 **Acesso:** [click-acai.vercel.app](https://click-acai.vercel.app/)


---

## ✨ Funcionalidades

- 🛒 **Montagem de produto personalizada** 
- 🛍️ **Carrinho de compras** 
- 📍 **Área de entrega configurável** 
- 🕒 **Status da loja dinâmico** 
- 💬 **Checkout via WhatsApp** 

## 🛠️ Tecnologias

- **HTML5** 
- **CSS3** 
- **JavaScript** 

## 📁 Estrutura do projeto

```
click-acai/
```
